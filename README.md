# AURA '26 — College Cultural Event Website

A responsive, multi-section webpage built using **pure HTML5 and CSS3** (with no databases, back-end servers, or JavaScript dependencies) for an annual college cultural festival.

🔗 **Live Demo:** [https://poetic-monstera-d19707.netlify.app](https://poetic-monstera-d19707.netlify.app)

---

## Features & Sections

- **Responsive Navigation Bar:** Sticky top navigation bar with smooth anchor links across sections and a mobile-friendly menu.
- **Hero & Event Highlights:** Showcases the festival dates (**March 20 – 22, 2026**), key metrics (`25+` cultural events, `₹2.5L` prize pool, `5,000+` student footfall), and a spotlight card for the Grand Pro-Show Finale.
- **Flagship Competitions:** Cards detailing core events—*Battle of Bands*, *Nritya & Street Beat*, *Nukkad Natak*, and *Canvas & Couture*—along with team formats and prize amounts.
- **3-Day Schedule:** Organized itinerary across **Day 01 (Rhythms & Roots)**, **Day 02 (Spotlight & Stage)**, and **Day 03 (Grand Finale)** with timings and venue locations.
- **Featured Performers:** Lineup highlights featuring *Aarav & The Echoes*, *DJ Kaira*, and *Urban Pulse Crew*.
- **Venue Information:** Campus address, main stage locations (*Open-Air Amphitheater* and *Tagore Memorial Auditorium*), entry/ID guidelines, shuttle details, and hospitality info.
- **Registration Section:** Form supporting participant and visitor sign-ups across event categories and participation types (*Solo*, *Group / Team*, *Audience*), paired with a confirmation state.

---

## Tech Stack

- **HTML5** — Semantic page structure and accessible form controls
- **CSS3** — Custom layout styling, grid/flexbox arrangement, responsive breakpoints, and interactive CSS states
